# A2UI programmatic templates and typesafe API

This directory contains specifications and requirements for A2UI Programmatic Templates and the companion Typesafe API Generator.

## Active proposals and documents

- [Requirements for the A2UI typesafe API generator](typesafe_api_generator_requirements.md): Exhaustive requirements covering template expansion, direct payload authoring, developer and maintainer ergonomics, compile-time diagnostics, and layout scenarios.
