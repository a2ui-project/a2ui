v1.0 JSON Schemas

A2UI v1.0 defines wire envelopes, shared types, catalog formats, and capability negotiation payloads across 11 canonical JSON Schemas included from specification/v1_0/json/. For the reference component catalog schema, see the v1.0 Basic Catalog Guide. For v0.9.1, see the v0.9.1 JSON Schemas.

Wire messages

agent_to_renderer.json

A2UI Message Schema — Describes a JSON payload for an A2UI message, which is used to dynamically construct and update user interfaces.

Source: specification/v1_0/json/agent_to_renderer.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v1_0/agent_to_renderer.json
Definitions & properties (8)
Definitions ($defs): CreateSurfaceMessage, Component, ComponentsList, UpdateComponentsMessage, UpdateDataModelMessage, DeleteSurfaceMessage, CallRendererFunctionMessage, AgentFunctionResponseMessage

renderer_to_agent.json

A2UI Renderer-to-Agent Event Schema — Describes a JSON payload for a renderer-to-agent event message.

Source: specification/v1_0/json/renderer_to_agent.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v1_0/renderer_to_agent.json
Definitions & properties (5)
Properties: version, action, callAgentFunction, rendererFunctionResponse, error

Capabilities

agent_capabilities.json

A2UI Agent Capabilities Schema — A schema for the agent capabilities object, which is used by an A2UI Agent to advertise its supported UI features to renderers. This can be embedded in an Agent Card for A2A or used in other transport protocols like MCP.

Source: specification/v1_0/json/agent_capabilities.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v1_0/agent_capabilities.json
Definitions & properties (1)
Properties: 1.0

renderer_capabilities.json

A2UI Renderer Capabilities Schema — A schema for the a2uiRendererCapabilities object, which is sent from the renderer to the agent as part of the A2A metadata to describe the renderer's UI rendering capabilities.

Source: specification/v1_0/json/renderer_capabilities.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v1_0/renderer_capabilities.json
Definitions & properties (1)
Properties: 1.0
