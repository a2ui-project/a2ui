# Restaurant finder example, Flutter UI with Python agent

This is the Flutter client for the restaurant finder demo featured in [Quickstart: Run A2UI in 5 Minutes](https://a2ui.org/quickstart). Refer to the guide for end-to-end setup and run instructions.

See a [demo video](https://github.com/user-attachments/assets/a2ac7024-e56e-4502-9db4-29ab37d8eef3) of how the example is expected to work.

## TL;DR: Run this example

1. Start the [restaurant finder service](../../../agent/adk/restaurant_finder/README.md)
2. Run flutter client by selecting `restaurant finder, Flutter renderer` run configuration in VS Code UI. See [launch.json](../../../../.vscode/launch.json) for run configuration details.
