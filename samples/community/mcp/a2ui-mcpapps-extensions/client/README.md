# A2UI over MCP Apps Dual-Mode Client

Lit-based host client demonstrating native A2UI rendering with zero iframe overhead and automatic fallback to sandboxed double-iframes.

## Scripts

- `yarn dev`: Starts Vite dev server on port 5173
- `yarn build`: Compiles TypeScript and builds production bundle
- `yarn test`: Runs unit tests via Vitest
- `yarn lint`: Runs ESLint
- `yarn format`: Formats code with Prettier
