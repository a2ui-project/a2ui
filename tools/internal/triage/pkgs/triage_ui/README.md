# triage_ui

The triage UI, a Flutter app that helps the triager go through the GitHub items
in the A2UI repository that need triage. It runs on macOS and the web.
[ui.blueprint.md](../../blueprints/features/ui.blueprint.md) describes what it
does. For now it only shows "Hello, world!".

## Running

```bash
flutter run -d macos
flutter run -d chrome
```

## Testing

```bash
flutter test
```
