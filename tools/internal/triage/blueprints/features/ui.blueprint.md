# Triage UI

Status: under construction.

The triage UI is a Flutter application that helps the triager go through the items that need triage. The terms are defined in [core.blueprint.md](../core.blueprint.md).

The triager runs it weekly, as part of [second line triage](../../../../../docs/contributing/triage/triage.md#second-line-triage-weekly-by-triager).
