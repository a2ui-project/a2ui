The model picks a pre-built widget and fills in its data.

  • +
    100% host-controlled Inherits your app's exact styling, components, and security model.
  • –
    Locked to pre-built views Agents can fill data slots, but cannot combine widgets for new requests.
  • –
    New flows require app releases Anything you didn't anticipate upfront falls back to plain chat text.

With A2UI: You register each pre-built widget as a catalog component or a server-side macro. The model picks one, and the A2UI renderer on the client draws it.

Tailored layouts assembled from your native catalog.

  • +
    Adapts to every prompt Agents compose multi-step flows on the fly from widgets you approve.
  • +
    Native & safe by default Streams declarative JSON data with two-way bindings — never executable code.
  • +
    One stream, every screen Renders natively across React, Lit, Angular, Flutter, SwiftUI, and Compose.

With A2UI: The model builds the screen from components in your catalog, and the renderer draws it with your own components as it streams in. In hosts that support MCP Apps, the same A2UI surface can run inside an MCP App.

The model writes HTML and JS that runs in a sandbox.

  • +
    Unrestricted custom visuals Built for bespoke 2D/3D canvases, interactive maps, and full mini-apps.
  • –
    Isolated from your design system Runs inside an iframe boundary with separate styling, state, and a11y.
  • –
    Tied to web & WebViews Ships heavier HTML/JS payloads rather than native mobile or desktop widgets.

With A2UI: Generated HTML and JS can run as an MCP App inside an A2UI surface, next to your native components.

What each team built

Alation · Alation AIOS

Alation shows its AI-generated data feeds with A2UI, in its own app and inside AI assistants such as Claude.

The Alation Intelligence Operating System (AIOS) builds its feeds using A2UI: metric cards, charts, and more. Each chart can show the SQL query and data behind it.

Ask Claude for a feed about profitable products, and the feed renders in the conversation using A2UI to render metric cards, charts, and custom components. The same feed with the same information can be viewed directly inside Alation with a nearly identical layout.

  • Alation ↗

ByteDance · Lynx

ByteDance built an A2UI renderer into Lynx, its open-source framework for mobile, web and desktop apps.

ByteDance released an A2UI renderer for Lynx, its cross-platform framework, in June. Lynx keeps streamed screens smooth and ships a default set of components built on its lynx-ui library.

In the Lynx GenUI Playground you can watch A2UI messages render natively, for example as a two-day trip planner for Kyoto. Lynx supports A2UI 0.9 today and is working with the A2UI team on 1.0 and A2UI Express.

Atlassian · Jira

Atlassian is bringing A2UI to Jira, where teams can assign work items to AI agents.

When an agent needs a follow-up from the team to finish a work item, such as a missing detail or a decision, it asks with an interactive card in the work item, and the team answers right there in Jira.

Google Cloud · Gemini Enterprise

Gemini Enterprise supports A2UI agents that organizations build and register.

Organizations can register their own agents that respond with A2UI. Gemini Enterprise renders those responses using the components in its A2UI component gallery, and supports A2UI 0.9.1 today.

The Google Cloud documentation covers registering an agent and hosting one on Cloud Run.

Gemini · Gemini Notebook

Gemini Notebook uses A2UI cards to confirm what you want before it creates a slide deck.

Ask Gemini Notebook for a slide deck and it replies with a card that asks two things: presenter slides or a detailed deck, and which topics to focus on. A review card follows with the format, focus and visual style, which you can edit before it generates.

The same cards guide Video Overviews on the web and on mobile.
