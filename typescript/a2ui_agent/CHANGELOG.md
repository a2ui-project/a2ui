## Unreleased

- Catalogs with cross-catalog `$ref`s into peer catalogs work in prompts, compilation, decompilation and payload validation. `resolveCatalogs` returns per-request copies of the active catalogs linked to each other and to the registered catalogs (pristine and transformed), without changing the registered catalogs, and never links an inline catalog the agent refuses. `DirectJsonFormat`, `DirectJsonPromptGenerator`, `DirectJsonParser`, the Express schema helpers and payload validation likewise work with linked copies (see `linkCatalogs` in `@a2ui/web_core`) and leave the catalogs passed to them unchanged.
- `DirectJsonExamples` is exported from the package root. `DirectJsonPromptGenerator.generateExamples(catalog)` renders every turn when examples are an ordered list of turns, as Python does, instead of returning an empty string. `zod-to-json-schema` is no longer a dependency.
- Catalog providers load documents with `Catalog.fromJson`, the pruning transformers derive the pruned catalog with `Catalog.withEntries`, so it keeps the source catalog's document-level fields and its remaining entries, whose definitions its `toJson()` writes as loaded, recomputes the `anyComponent` and `anyFunction` unions and drops `$defs` that only pruned entries referenced, and `DirectJsonPromptGenerator` embeds the agent-to-renderer schema, the pruned `common_types` schema, and each active catalog's `Catalog.toJson()` document ([#3053](https://github.com/a2ui-project/a2ui/issues/3053)). Express reads component and function schemas from `Catalog.toJson()` instead of a copy of the loaded document kept beside the catalog, so it works with catalogs defined in code, such as the basic catalogs of `@a2ui/web_core`, and with pruned catalogs, and changes the caller makes to a document after loading it no longer reach Express ([#1626](https://github.com/a2ui-project/a2ui/issues/1626)).
- Initial implementation of `@a2ui/agent`, supporting A2UI protocol versions v0.9 and v1.0 and the Direct JSON and Express inference formats ([#2814](https://github.com/a2ui-project/a2ui/pull/2814), [#2916](https://github.com/a2ui-project/a2ui/pull/2916), [#2815](https://github.com/a2ui-project/a2ui/pull/2815)).
