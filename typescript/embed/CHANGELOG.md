## Unreleased

- Add `@a2ui/embed`, with the versioned contract between an MCP server and its A2UI app in `@a2ui/embed/contract`: the tool result shape, `EmbedPayload`, the `a2ui_action` tool's `ActionCall`, the catalog schema file, and the `toToolResult`, `readEmbedPayload` and `checkContractVersion` helpers. [#4297](https://github.com/a2ui-project/a2ui/pull/4297)
- Add `@a2ui/embed/mcp/server`, which serves an A2UI app from an MCP server: `createA2uiApp` registers the app resource, `app.tool` registers tools whose A2UI results render in the app, `app.action` and `app.followUp` handle the app's actions, and `app.validate` checks A2UI messages against the A2UI specification and the app's catalogs. `@modelcontextprotocol/sdk` is a new peer dependency. [#4298](https://github.com/a2ui-project/a2ui/pull/4298)
- Add `startEmbedApp` in `@a2ui/embed/mcp`, the MCP App runtime: it renders the A2UI payload of each tool result with the Lit renderer and the given catalogs, shows an error card for invalid payloads, sends A2UI actions to `a2ui_action` and applies the result in place or posts its follow-up, follows the host theme and size, and shares the data model of `sendDataModel` surfaces with the model through `ui/update-model-context` when the user changes it, directly or through an action. [#4299](https://github.com/a2ui-project/a2ui/pull/4299)
- Add the `a2ui-embed build` command and `@a2ui/embed/build` (`defineConfig`, `build`, `basicCatalog`). It builds the app from a config file into one HTML file that loads nothing from the network, and writes the catalog schema file next to it. [#4300](https://github.com/a2ui-project/a2ui/pull/4300)
- Render markdown in the app. `startEmbedApp` takes a `markdown` renderer for the basic catalog's body `Text`, and the app built by `a2ui-embed build` renders it with `@a2ui/markdown-it` unless the config sets `markdown: false`. Links open through the host's `ui/open-link` request instead of navigating the app's frame. `@a2ui/markdown-it` and `@lit/context` are new dependencies. [#4334](https://github.com/a2ui-project/a2ui/pull/4334)
