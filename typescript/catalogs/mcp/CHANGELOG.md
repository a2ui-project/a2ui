## Unreleased

- Add the `McpApp` universal component and `mcpCatalog`. `A2uiMcpApp` renders an MCP App's `htmlContent` inside the sandbox proxy and connects it to the surface through `McpAppBridge`, an `@modelcontextprotocol/ext-apps` `AppBridge` host: tool calls are limited to `allowedTools` and dispatched as `callMcpTool` actions, function calls are limited to `allowedFunctions` and validated against the declared JSON Schema before the catalog function runs, and `data.paths` bindings are pushed to the app once it is initialized and kept in sync in both directions. Denied and invalid calls answer with `McpError(InvalidParams)`, failures with `InternalError`. The root entry also exports the sandbox configuration (`configureSandbox`, `resolveSandboxUrl`, `getSandboxConfig`, `resetSandboxConfig`, `SANDBOX_PAGES`, `DEFAULT_SANDBOX_BASE_URL`); the package ships the proxy pages in `sandbox/` and the host serves that directory itself. [#2799](https://github.com/a2ui-project/a2ui/pull/2799)
- **BREAKING CHANGE**: The root entry point now also exports the component and needs a browser. Code that runs in Node, such as an agent that only needs the catalog functions, must import `@a2ui/catalog-mcp/functions`, which is the former root entry with the same exports. `@a2ui/catalog-mcp/components` exports the component and the bridge on their own. [#2799](https://github.com/a2ui-project/a2ui/pull/2799)
- First publishable version, 0.1.0: the package is no longer private. `@a2ui/web_core` and `lit` become peer dependencies, `@modelcontextprotocol/ext-apps` is a new dependency and `@modelcontextprotocol/sdk` now requires `^1.29.0`. [#2799](https://github.com/a2ui-project/a2ui/pull/2799)
- The bundled `catalog.json` now declares the `McpApp` component, which renders a sandboxed MCP App in a surface. Its `allowedFunctions` property is a map of function name to the JSON Schema of the function's arguments rather than a list of names; `allowedTools` stays a list of tool names. This package still implements the catalog functions only, so a renderer that shows MCP Apps must provide its own `McpApp` component. [#2795](https://github.com/a2ui-project/a2ui/pull/2795)
