- `@a2ui/catalog-mcp` implements the A2UI MCP catalog (`catalogs/mcp/v1/catalog.json`, protocol v1.0, bundled as `@a2ui/catalog-mcp/catalog.json`; the id is `MCP_CATALOG_ID`). It provides `callMcpTool` as `CallMcpToolImplementation`: the function runs a tool on a connected MCP server, returns the raw result, applies the A2UI messages found in the result and in the UI resources it references to the host's `MessageProcessor`, and hands `ui://` MCP App resources (`text/html;profile=mcp-app`) to the host as `McpAppResourcePayload`; its `arguments` may also be a function call, for a tool whose argument is named `path`. Hosts configure the package once with `configureMcpCatalog({getMcpClientForTool, processor, defaultVersion?, onMcpAppResource?, sandbox?})`, and serve the double-iframe sandbox proxy shipped in `sandbox/` for components that embed untrusted content.
