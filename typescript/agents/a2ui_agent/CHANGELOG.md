## Unreleased

- **BREAKING**: A parser holds no state, and validation is separate from translation ([#3262](https://github.com/a2ui-project/a2ui/issues/3262), [#3263](https://github.com/a2ui-project/a2ui/issues/3263)). To migrate:
  1. `Parser.parseResponse(content, wrapped)` takes an options object: `parseResponse(content, {wrapped, state})`. It checks every message against the `RendererState` it is given, or a new, empty one, so an update to a surface the response does not create is now rejected unless the state holds the surface. A response is checked as a whole: a component may name a child that a later block adds, the trees of the surfaces it touches are checked once every block is applied, and the messages are applied to the state all or nothing. An error carries the parts read before the failing block in `partialResults`, or only the text when the tree check fails, since that check spans every block; none of them is applied to the state.
  2. `Parser.parseChunk` and `Parser.parseStream`: open a stream with `parser.openStream({wrapped, state})` and pass each chunk to `feed(chunk)`, then call `close()`. The `ResponseStream` holds the buffers of one response and applies each message to its state as it emits it. `close` emits text held back as a possible tag, throws a `ParseError` if a block is still open, and checks the tree of an unwrapped stream. A stream that throws has ended.
  3. `Parser.compile` only translates a block into messages and reports what the notation gets wrong. To translate and check one block, call `parseResponse(block, {wrapped: false})`. A `Parser` subclass also implements the `catalogs` property.
  4. `DirectJsonStreamProcessorImpl`, `DirectJsonStreamProcessor`, `DirectJsonStreamProcessorFactory` and `DirectJsonStreamProcessorOptions` are removed. `DirectJsonParser(catalogs, {progressiveKeys})`, `DirectJsonFormat(catalogs, examples, {progressiveKeys})` and `DirectJsonFormatFactory({progressiveKeys})` take the keys whose string values a stream heals; the format's default is `['text']`, and the parser's is none. `DirectJsonResponseStream` is exported.
- Streamed Direct JSON follows `conformance/agent/direct_json/response_streaming.yaml`, as Python does, and every v0.9 and v1.0 case of it passes. A message is emitted as soon as it reads and the state accepts it, and again as it grows; only `updateComponents` and `updateDataModel` are emitted while they grow, and any other message, such as `createSurface`, `deleteSurface` or `callRendererFunction`, is held until its object closes; no `loading_*` placeholder components are added; a message for a surface that does not exist yet is held back; text outside blocks is trimmed at its edges; and every streamed message gets the same checks as one in a whole response, with no option to skip them. The stream keeps no copy of surface state of its own: it reads surfaces, components and catalogs from its `RendererState`. A stream reads each chunk once, so it takes time in proportion to the response: the scan for the close tag and the read of the open block go on where the previous chunk left them, a message that has closed is not read or checked again, and a growing `updateComponents` is checked for the components it adds and a growing `updateDataModel` for the lists and maps its value gains. Streaming 400 components in 40-character chunks took 7.0 s before and 0.13 s now. The timing suites `conformance/agent/direct_json/scaling.yaml` and `conformance/agent/express/scaling.yaml` run with `yarn test:timing`, and in CI.
- `DirectJsonParser.unwrap` reads tags the way Python's does: a response without tags is one text part, a block still open at the end is a part that is not final, and tags may carry attributes. The Direct JSON parser reads blocks with a reader ported from Python's, which accepts trailing commas and raw line breaks inside strings, and reports a block that is not JSON as a `ParseError`.
- **BREAKING**: `A2uiRequestProcessor` no longer keeps a `MessageProcessor` for its whole life, so state no longer carries over between `parseResponse` calls by accident. Without a state, each call checks the response against a new one, as a chat agent wants. A canvas agent creates a state with `createState()` and passes it to `parseResponse` and `openStream`, or binds one with `new A2uiRequestProcessor(catalogs, examples, factory, {state})` or `A2uiGenerator.createProcessor(capabilities, factory, {state})`. A state that holds other catalogs than the processor is rejected with `A2uiCatalogError`. `A2uiRequestProcessor.acceptsState` tells whether a state holds the processor's catalogs, treating a v0.9 and a v0.9.1 catalog with the same id as the same catalog, as `RendererState` does, so an agent that keeps a state per conversation can tell when to make a new one. `A2uiRequestProcessor.parser` returns the one parser the processor reuses, and `openStream` reads a streamed response.
- **BREAKING**: Express output is checked against the catalogs and the surface trees like Direct JSON output, since the check moved from `DirectJsonParser.compile` to `Parser.parseResponse`. An Express block that assigns no `root` compiles to an `updateComponents`, which now needs a state that holds the surface.
- `A2uiGenerator.createProcessor` checks each example that is not text with `validatePayload`, instead of only checking that its component types exist.

- Add `RendererState`, the agent's mirror of the surfaces a renderer holds ([#3263](https://github.com/a2ui-project/a2ui/issues/3263)). It wraps one web_core `MessageProcessor`, created once with the linked catalogs, and checks each outbound message against everything applied before it. `apply(payload)` checks and applies messages atomically: if one is rejected, the state is left as it was. `transaction(fn)` extends that to everything `fn` applies, and transactions nest. Rollback uses an undo log: each message records what it replaced (the components it adds or replaces, with a copy of the previous properties of a component updated in place, and the data model value at its path), and a failure reverts those records, latest first. A deleted surface is restored by replaying it through the processor, so each component keeps its own catalog. No surface is copied when a message is applied or a transaction opens, so applying n messages to one surface takes time in proportion to n. `checkTopology(surfaceIds)` checks that each surface has its root, that every reference resolves, and that every component added or replaced since the last check is reachable from the root. A component that an update leaves unreachable by rewriting its parent's children is accepted, since the protocol has no message that removes one component. An update to a surface the state never saw created is rejected, as a renderer rejects it. `markChecked(surfaceIds)` stops holding the components each surface changed against later `checkTopology` calls: a stream that fails after emitting messages, and a block cut off at the end of a response, mark their surfaces checked, since the renderer holds those components and no message removes one. Dangling references and a missing root are still reported. `RendererState`, `validatePayload` and the `SurfaceModel` type that `RendererState.getSurface` returns are exported from the package root.
- `validatePayload` runs the payload through a short-lived `RendererState` that assumes a surface the payload only updates already exists, instead of building a new `MessageProcessor` for the created surfaces and another for each candidate catalog of each updated surface. Its results are unchanged, except that a component of a created surface may now name a child that a later message of the same payload adds, as in Python. It also accepts one message on its own, not only a list, as `RendererState.apply` does.
