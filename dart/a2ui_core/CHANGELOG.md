# [a2ui_core](https://pub.dev/packages/a2ui_core) Changelog

## 0.1.2

- Injected clocks into timestamps and timeouts (#2239).
- Added `Clock`, `SystemClock`, and `FakeClock` primitives for deterministic time and timeout testing.
- Added optional `clock` parameter to `SurfaceModel`, `SurfaceGroupModel`, and `MessageProcessor`.
- Added `CancellationSignal.timeout` with optional `timerFactory`.

## 0.1.1

- The source code is moved from genui repo to a2ui repo.

## 0.1.0
