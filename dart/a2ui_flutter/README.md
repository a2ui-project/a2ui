# A2UI Flutter

A new `a2ui_flutter` package is coming.

In the meantime, please use the [Flutter Gen UI SDK](https://github.com/flutter/genui), which provides the official Flutter renderer for A2UI:

- [`genui`](https://pub.dev/packages/genui): The core framework for employing Generative UI in Flutter applications.
- [`genui_a2a`](https://pub.dev/packages/genui_a2a): Allows the Flutter Gen UI SDK to act as a renderer for UIs generated by an A2UI backend agent, integrating with the A2UI protocol.
