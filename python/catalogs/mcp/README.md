# `a2ui-catalog-mcp`

Python package for the [A2UI MCP catalog](../../../catalogs/mcp/README.md). The catalog schema lives at [`catalogs/mcp/catalog.json`](../../../catalogs/mcp/catalog.json); the TypeScript implementation is [`@a2ui/catalog-mcp`](../../../typescript/catalogs/mcp/).

This package is a placeholder that reserves the name and workspace slot. It does not ship an implementation yet.
