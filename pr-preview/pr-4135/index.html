A2UI is an open-source generative UI framework that enables agents to select, compose, or build experiences that are personalized in the moment, native to your brand, and secure. Using an agent-optimized protocol, native renderers, and SDKs for agent frameworks and harnesses, A2UI achieves low latency, predictability, and visual fidelity across all screens.

Personalized in the moment

Your agent constructs UI that adapts to each user's unique needs and preferences.

Native to your brand

Your design system, locked. Agents place only components you registered.

Fast, reliable, secure in production

Agents compose UI with A2UI Express or Jev-style decision models. Macros bind data and components reliably, and the client streams it in as the agent thinks.

The model picks a pre-built widget and fills in its data.

  • +
    100% host-controlled Inherits your app's exact styling, components, and security model.
  • –
    Locked to pre-built views Agents can fill data slots, but cannot combine widgets for new requests.
  • –
    New flows require app releases Anything you didn't anticipate upfront falls back to plain chat text.

With A2UI: You register each pre-built widget as a catalog component or a server-side macro. The model picks one, and the A2UI renderer on the client draws it.

Macros →

Tailored layouts assembled from your native catalog.

  • +
    Adapts to every prompt Agents compose multi-step flows on the fly from widgets you approve.
  • +
    Native & safe by default Streams declarative JSON data with two-way bindings — never executable code.
  • +
    One stream, every screen Renders natively across React, Lit, Angular, Flutter, SwiftUI, and Compose.

With A2UI: The model builds the screen from components in your catalog, and the renderer draws it with your own components as it streams in. In hosts that support MCP Apps, the same A2UI surface can run inside an MCP App.

How A2UI works → A2UI in MCP Apps →

The model writes HTML and JS that runs in a sandbox.

  • +
    Unrestricted custom visuals Built for bespoke 2D/3D canvases, interactive maps, and full mini-apps.
  • –
    Isolated from your design system Runs inside an iframe boundary with separate styling, state, and a11y.
  • –
    Tied to web & WebViews Ships heavier HTML/JS payloads rather than native mobile or desktop widgets.

With A2UI: Generated HTML and JS can run as an MCP App inside an A2UI surface, next to your native components.
