# v1.0 JSON Schemas

> Canonical JSON Schemas for A2UI v1.0 wire messages, common types, catalog definitions, and capabilities.

Canonical URL: https://a2ui.org/specification/v1.0/schemas/

A2UI v1.0 defines wire envelopes, shared types, catalog formats, and capability negotiation payloads across 11 canonical JSON Schemas included from `specification/v1_0/json/`. For the reference component catalog schema, see the [v1.0 Basic Catalog Guide](https://a2ui.org/specification/v1.0-basic-catalog-implementation-guide/#basic_catalog.json). For v0.9.1, see the [v0.9.1 JSON Schemas](https://a2ui.org/specification/v0.9.1/schemas/).
