v0.9.1 JSON Schemas

A2UI v0.9.1 defines wire messages, shared types, data models, and capability negotiation payloads across 10 canonical JSON Schemas included from specification/v0_9_1/json/. Version v0.9.1 supersedes v0.9 while retaining v0_9 in $id URIs for backward compatibility. For the reference component catalog schema, see the v0.9.1 Basic Catalog Guide. For the current version, see the v1.0 JSON Schemas.

Wire messages

server_to_client.json

A2UI Message Schema — Describes a JSON payload for an A2UI message, which is used to dynamically construct and update user interfaces.

Source: specification/v0_9_1/json/server_to_client.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v0_9/server_to_client.json
Definitions & properties (4)
Definitions ($defs): CreateSurfaceMessage, UpdateComponentsMessage, UpdateDataModelMessage, DeleteSurfaceMessage

client_to_server.json

A2UI Client-to-Server Event Schema — Describes a JSON payload for a client-to-server event message.

Definitions & properties (3)
Properties: version, action, error

Capabilities

server_capabilities.json

A2UI Server Capabilities Schema — A schema for the server capabilities object, which is used by an A2UI server (or Agent) to advertise its supported UI features to clients. This can be embedded in an Agent Card for A2A or used in other transport protocols like MCP.

Source: specification/v0_9_1/json/server_capabilities.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v0_9/server_capabilities.json
Definitions & properties (1)
Properties: v0.9

client_capabilities.json

A2UI Client Capabilities Schema — A schema for the a2uiClientCapabilities object, which is sent from the client to the server as part of the A2A metadata to describe the client's UI rendering capabilities.

Source: specification/v0_9_1/json/client_capabilities.json ↗ · Raw JSON ↗ · Permalink · $id: https://a2ui.org/specification/v0_9/client_capabilities.json
Definitions & properties (3)

Properties: v0.9
