# v0.9.1 JSON Schemas

> Canonical JSON Schemas for A2UI v0.9.1 wire messages, common types, data models, and capabilities.

Canonical URL: https://a2ui.org/specification/v0.9.1/schemas/

A2UI v0.9.1 defines wire messages, shared types, data models, and capability negotiation payloads across 10 canonical JSON Schemas included from `specification/v0_9_1/json/`. Version `v0.9.1` supersedes `v0.9` while retaining `v0_9` in `$id` URIs for backward compatibility. For the reference component catalog schema, see the [v0.9.1 Basic Catalog Guide](https://a2ui.org/specification/v0.9.1-basic-catalog-implementation-guide/#basic_catalog.json). For the current version, see the [v1.0 JSON Schemas](https://a2ui.org/specification/v1.0/schemas/).
