## Proposal


### Blueprint drafts vs implemented

Merged blueprints must be in-sync with code. Blueprint drafts should exist as proposals - in docs or issues, or be marked as drafts. In case of cross-language implementation, cross-langiuguage deviations should be clearly explained in blueprint.
