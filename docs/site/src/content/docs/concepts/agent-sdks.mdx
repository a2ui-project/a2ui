An A2UI Agent SDK connects a language model or server-side agent to the A2UI protocol by generating catalog-driven prompt instructions, compiling model output into wire messages, and validating surface state before messages leave the server. Official Agent SDKs are published for TypeScript, Python, and Dart.

Swift and Kotlin AndroidX target client-side rendering and are listed in [Renderer SDKs](/concepts/renderer-sdks/); for legacy `v0.8` and `v0.9` JVM servers, [`kotlin/agent_sdk_legacy`](https://github.com/a2ui-project/a2ui/tree/main/kotlin/agent_sdk_legacy) remains in the repository.

## Core SDK foundation

Every Agent SDK builds on its language's Core SDK, which implements the [wire message](/concepts/messages/) models, [`Catalog`](/concepts/catalogs/) schemas, [surface `DataModel` and binding](/concepts/data-binding/) evaluators, and validation rules shared with client renderers. Sharing one Core SDK per language keeps server-side validation identical to client-side message processing.

## What an Agent SDK does

Your application controls model selection, tool execution, and conversation state, while the Agent SDK abstracts `v0.9.1` and `v1.0` wire differences behind `A2uiGenerator` and handles five protocol tasks:

1. Negotiates active [`Catalog`](/concepts/catalogs/) definitions and protocol versions against the capabilities reported by the client renderer (see [Overview](/concepts/overview/)).
2. Generates skills, system prompt instructions, and examples directly from catalog schemas and `instructions`, replacing hand-written prompts that go out of date when components change.
3. Compiles streaming or batch model output from [swappable inference formats](/concepts/inference-formats/) (such as compact Express syntax, which cuts output tokens without client changes, or chunk-healed Direct JSON) into standard A2UI [wire messages](/concepts/messages/).
4. Validates outgoing messages statefully against `RendererState` on the server so broken component IDs, placement violations, or schema mismatches can be fed back to the model for self-correction before transmission.
5. Provides optional server-side `@macro` expansion (`MacroExpander` in `a2ui-agent-sdk`) and integrates with agent frameworks and transports including [Google ADK](https://github.com/google/adk-python) (`a2ui-adk`) and the [A2A protocol](https://a2a-protocol.org/) (`a2ui-a2a`).
