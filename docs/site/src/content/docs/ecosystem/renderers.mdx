This page lists community renderers, agent libraries, developer utilities, and related projects built around the A2UI protocol.

<Aside type="note" title="Community maintenance">
  Third-party projects listed here are maintained by their respective authors and organizations, not
  by the core A2UI maintainers. Check each repository for license terms, protocol version support,
  and release status.
</Aside>

<Aside type="tip" title="Official SDKs">
  For first-party SDKs maintained by the A2UI team, see the [Agent SDKs](../../concepts/agent-sdks/)
  guide (TypeScript, Python, Dart) and [Renderer SDKs](../../concepts/renderer-sdks/) guide (Web
  with React, Lit, and Angular; Flutter; Swift; and Jetpack Compose), as well as the official
  [`@a2ui/react`](https://www.npmjs.com/package/@a2ui/react) package.
</Aside>

The official [`@a2ui/markdown-it`](https://www.npmjs.com/package/@a2ui/markdown-it) package, maintained in the repository under `typescript/renderers/markdown-it`, enables Markdown formatting within A2UI Text components across web renderers.

## Community showcase and contributing

The A2UI project welcomes community submissions and third-party tooling.

### How to submit a project

Follow these steps to submit a renderer, library, or tool for inclusion in this directory:

1. Create a fork of the [a2ui-project/a2ui](https://github.com/a2ui-project/a2ui) repository on GitHub.
2. Sign the [Google Contributor License Agreement](https://cla.developers.google.com/) if you have not already done so.
3. Add your project row to `docs/site/src/content/docs/ecosystem/renderers.mdx` with package details, platform support, supported protocol versions, and repository links.
4. Open a pull request against `a2ui-project/a2ui` with a description of the project and verification details or demo links.
5. Share your project on [GitHub Discussions](https://github.com/a2ui-project/a2ui/discussions) with an optional demo video or walkthrough.

### Listing criteria

Submissions are evaluated against the following guidelines:

1. The project should have an open-source repository, typically licensed under Apache 2.0 or MIT.
2. Documentation must explicitly state supported protocol versions (`v0.8`, `v0.9` / `v0.9.1`, or `v1.0`).
3. Client renderers should support core layout, text, input, and action components.
4. The repository should include clear installation instructions and a minimal runnable example.
5. Projects should reflect active maintenance. Projects that are no longer maintained should be marked as archived.

### Code of conduct and participation

All community members and contributors are expected to follow [Google's Open Source Community Guidelines](https://opensource.google/conduct/) as described in [CONTRIBUTING.md](https://github.com/a2ui-project/a2ui/blob/main/CONTRIBUTING.md).

For discussions and general questions, participate in [GitHub Discussions](https://github.com/a2ui-project/a2ui/discussions).

To report bugs or feature requests, use [GitHub Issues](https://github.com/a2ui-project/a2ui/issues).

To report security vulnerabilities, do not open a public issue. Follow the instructions in [Google Vulnerability Reporting](https://g.co/vulnz) or contact the project maintainers privately.
