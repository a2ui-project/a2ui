> [!IMPORTANT] Current Specification
> **A2UI v1.0** is the current specification. Compared to [v0.9.1](./v0.9.1-a2ui.md), v1.0 renames the wire envelopes to `agent_to_renderer` and `renderer_to_agent`, prefixes dynamic bindings with `@` (`@path` and `@call`) and component envelope keys with `@` (`@catalogId`, `@accessibility`, `@metadata`, `@checks`), adds bidirectional function RPC messages (`callRendererFunction`, `callAgentFunction`, `rendererFunctionResponse`, `agentFunctionResponse`), and supports per-component `@catalogId` mixing and single-message `createSurface` payloads. See the [v1.0 Evolution Guide](./v1.0-evolution-guide.md) and [v1.0 JSON Schemas](./v1.0-schemas.mdx).
