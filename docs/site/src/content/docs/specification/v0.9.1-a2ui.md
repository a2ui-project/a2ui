> [!NOTE] Supersedes v0.9
> **A2UI v0.9.1** supersedes `v0.9` with minor schema and patch refinements while retaining `v0.9` / `v0_9` in wire `"version"` examples for compatibility. Each v0.9.1 schema declares its own `$id` under `https://a2ui.org/specification/v0_9_1/`, except `common_types.json`, which v0.9.1 shares unchanged with v0.9 and which keeps its `v0_9` `$id`. See the [v0.9.1 Evolution Guide](./v0.9.1-evolution-guide.md), [v0.9.1 JSON Schemas](./v0.9.1-schemas.mdx), and [v1.0 Protocol Specification](./v1.0-a2ui.md). New projects should target v1.0, the current version.
