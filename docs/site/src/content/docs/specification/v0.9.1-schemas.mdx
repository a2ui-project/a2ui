A2UI v0.9.1 defines wire messages, shared types, data models, and capability negotiation payloads across 10 canonical JSON Schemas included from `specification/v0_9_1/json/`. Version `v0.9.1` supersedes `v0.9`. Each schema declares its own `$id` under `https://a2ui.org/specification/v0_9_1/`, except `common_types.json`, which v0.9.1 shares unchanged with v0.9 and which keeps its `v0_9` `$id`. For the reference component catalog schema, see the <a href={`${base}/specification/v0.9.1-basic-catalog-implementation-guide/#basic_catalog.json`}>v0.9.1 Basic Catalog Guide</a>. For the current version, see the <a href={`${base}/specification/v1.0/schemas/`}>v1.0 JSON Schemas</a>.
