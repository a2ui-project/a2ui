# Internal documentation

This directory holds background documentation for A2UI project processes and infrastructure: motivations, design decisions, invariants, and explanations of how tools and workflows operate.

These documents describe the implementation details of team processes. You do not need to read them during day-to-day execution of a process (step-by-step instructions belong in [`docs/contributing/`](../contributing/)). Read or update them when troubleshooting, auditing, or changing how a process works.

## Contents

1. [`triage_explainer.md`](triage_explainer.md): Goals, invariants, label definitions, and bot rules behind the issue and pull request triage process described in [`docs/contributing/triage.md`](../contributing/triage.md).
